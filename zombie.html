Zombie FPS

Play Demo ↗ View on GitHub ↗

Watch trailer

Approach

Heavily inspired by the Call of Duty:Zombies series I developed this project during my specialization & graduation at Futuregames, the game includes a weapon system (Firing, Reloading, Fire Selector), perk system (8 perks), currency system (points and buyables), weapon upgrade system (Pack-A-Punch), co-op multiplayer via Steam, weapon attachment system and the zombie AI and round system, with all that I also needed a flexible and scalable stat system. This was a very fun project to work on and also a challenging one from a structure point. I ended up using the composition workflow, I tried to keep all the core systems encapsulated in single Actor Components, this worked really well for me as I was able to remove or change certain behaviours without changing the main actor classes (Character and Weapons). The game also features DLSS and Frame Generation support.
